## El problema

La mayoría de las empresas medianas de Bolivia corren sobre **Excel, WhatsApp y memoria**. Saben cuánto vendieron, pero no quién les debe. Tienen la información, pero no la tienen junta. Cada mes pierden plata en cobranzas que nadie persiguió, stock que nadie contó y clientes que nadie volvió a llamar.

El software enlatado no lo resuelve: obliga a la empresa a adaptarse al sistema. **Nosotros hacemos lo contrario.**

<br/>

## Qué construimos

| | |
|---|---|
| **Gestión de cartera y cobranza** | Clientes, planes de pago, mora, contratos y arqueo. Producto propio, corriendo en producción. |
| **Reservas y operaciones** | Turismo, transporte y servicios: agenda, disponibilidad, confirmaciones. |
| **Inventario y ventas** | Stock, importación, márgenes y reportes que el dueño entiende sin capacitación. |
| **Automatización e IA aplicada** | Dentro del flujo de trabajo real, no como demo de feria. |
